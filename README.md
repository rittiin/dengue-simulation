# Dengue Simulation for Surveillance

ห้องปฏิบัติการจำลองการระบาดของ **โรคไข้เลือดออก** แบบ 3 มิติ สำหรับฝึกคิดเชิงระบาดวิทยา

🔗 **ทดลองใช้:** <https://ddssimu.pages.dev>

![ภาพหน้าจอ](docs/screenshot.jpg)

> ⚠️ ใช้ **ข้อมูลสมมติทั้งหมด** — ไม่มีข้อมูลผู้ป่วยจริง ผลการจำลองใช้เพื่อการเรียนรู้ ไม่ใช่การพยากรณ์สถานการณ์จริง

---

## ทำอะไรได้บ้าง

- **แผนที่ 3D แบบ grid** (ช่องละประมาณ 200×200 ม.) — หมุน/เลื่อน/ซูมได้ คลิกช่องเพื่อดูข้อมูลรายพื้นที่
- **เลือกสีพื้นที่** ตามระดับความเสี่ยง, Rt ระดับหมู่บ้าน, ดัชนีลูกน้ำ (HI), ความหนาแน่นประชากร หรือการใช้ที่ดิน
- **ความสูงแท่ง** แสดงผู้ป่วย 7 / 14 / 28 วัน หรือผู้ป่วยสะสม
- **ไทม์ไลน์รายวัน** เล่น/ข้ามได้ ปรับความเร็ว 2–20 วันต่อวินาที
- **Rt ตามเวลา** ประมาณจากวันเริ่มป่วย พร้อมช่วง 95% CrI เทียบกับ Rt ของแบบจำลอง (เฉลี่ย 7 วัน)
- **Epidemic curve** ตามวันเริ่มป่วยและวันรายงาน แยก ยืนยัน / น่าจะเป็น / สงสัย
- **แท็บมาตรการและ Scenario** สำหรับทดลองและเปรียบเทียบผลของการควบคุมโรค
- **บันทึกภาพ** หน้าจอไปใช้นำเสนอ

## เหมาะกับใคร

- นักระบาดวิทยา และทีม SRRT
- เจ้าหน้าที่ควบคุมพาหะนำโรค
- ผู้บริหารที่ต้องเข้าใจผลของมาตรการก่อนตัดสินใจ
- ผู้สอน/ผู้เรียนด้านระบาดวิทยาโรคติดต่อนำโดยแมลง

## แนวคิดของแบบจำลอง

การแพร่เชื้อเกิดผ่านยุงพาหะ แบบจำลองจึงเชื่อมผู้ป่วย ยุง สภาพแวดล้อม และมาตรการควบคุมเข้าด้วยกันในระดับ grid

- **R0** — จำนวนผู้ป่วยใหม่เฉลี่ยจากผู้ติดเชื้อ 1 ราย เมื่อประชากรไวต่อการติดเชื้อทั้งหมด ไม่มีมาตรการ และอ้างอิงสภาพอากาศฤดูฝน 28°C
- **Rt** — ประมาณจากผู้ป่วยจำลองตามวันเริ่มป่วย ช่วงวันท้าย ๆ เป็นค่าเบื้องต้นเพราะการรายงานยังไม่ครบ
- **ความไม่แน่นอนของข้อมูล** — จำลองความครบถ้วนและความล่าช้าของการรายงาน รวมถึงความคลาดเคลื่อนของการสำรวจลูกน้ำ/ovitrap

| ระดับความไม่แน่นอน | รายงานครบ | ล่าช้าเฉลี่ย |
|---|---|---|
| ต่ำ | ~85% | 2 วัน |
| ปานกลาง | ~65% | 4 วัน |
| สูง | ~45% | 7 วัน |

### พารามิเตอร์หลัก

| พารามิเตอร์ | ความหมาย |
|---|---|
| R0 | ค่าการแพร่เชื้อพื้นฐาน |
| สัดส่วนประชากรไวต่อการติดเชื้อ | สัดส่วนผู้ที่ยังติดเชื้อได้ |
| วันเริ่มจำลอง / จำนวนวัน | ช่วงเวลาที่จำลอง |
| ผู้ติดเชื้อตั้งต้น | จำนวนผู้ติดเชื้อเมื่อเริ่มจำลอง |
| ผู้ติดเชื้อนำเข้า (ราย/วัน) | การนำเชื้อเข้าจากนอกพื้นที่ |
| ระดับการเดินทางในพื้นที่ | การเคลื่อนที่ระหว่าง grid |
| สัดส่วนผู้ติดเชื้อที่มีอาการ | ส่วนที่จะถูกพบและรายงานได้ |
| Random seed | ทำให้ผลการจำลองซ้ำได้ |
